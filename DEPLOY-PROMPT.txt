## 项目信息
- 产品名：线索雷达（AI 自动获客演示平台）
- 技术栈：React 18 + Vite 5，纯前端 SPA，无后端、无数据库、无登录、无真实 API
- 交付物：附件 lead-radar-dist.zip（122 KB，18 个文件）
- zip 内容：完整源码（src/）、已构建好的生产产物（dist/）、部署说明（DEPLOY.md）、package.json / vite-lock / vite.config.js

## 部署要求
1. 先解压 zip，并阅读根目录下的 DEPLOY.md（里面有完整部署文档）
2. 优先使用 zip 里现成的 dist/ 目录做静态托管，不需要重新构建；如果你判断有必要重建，可在 Node ≥ 18 环境执行 npm install && npm run build（Windows 环境若报 esbuild 平台包缺失，补装 npm install @esbuild/win32-x64 --no-save）
3. 部署方式由你选择（服务器 Nginx / Vercel / Netlify / Cloudflare Pages 等任一静态托管方案均可），但要保证：
   - 访问域名根路径能打开 index.html
   - 配置 SPA 回退（try_files $uri /index.html 或等效设置）
   - 开启 HTTP(S)，能通过公网链接访问
4. 字体使用 Google Fonts CDN（DM Sans + Noto Sans SC），部署环境需允许访问 fonts.googleapis.com；若无法访问会自动回退系统字体，不影响功能，不要为此改代码

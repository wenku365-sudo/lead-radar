# 线索雷达 · AI 自动获客演示

输入一个获客任务，体验 AI 解析、采集动画、客户筛选与跟进流程。

**这是纯前端演示，无需登录、数据库、账号配置或后端服务。** 客户、任务和采集内容均为模拟数据。

## 在线预览

https://wenku365-sudo.github.io/lead-radar/

页面打开即进入演示模式。推送到 `main` 后，GitHub Actions 会自动构建并发布到 GitHub Pages。

支持任意自定义行业任务；采集弹窗约 10 秒完成；意向客户先展示 15 条，其余逐条插入；行业选择默认收起，自定义行业优先显示。

## 本地运行

需要 Node.js 22 或更高版本。

```bash
npm install
npm run dev
```

打开 Vite 输出的本地地址即可体验。发布构建：

```bash
npm run build
```

## 页面

| 页面 | 体验内容 |
| --- | --- |
| 首页 | 产品演示首页与获客流程 |
| AI 交代任务 | 输入目标客户描述，生成任务 |
| 工作台 | 客户统计与行业概览 |
| 采集数据 | 观看任务采集动画 |
| 意向客户 | 筛选客户、查看详情与推荐回复 |
| 跟进工作台 | 更新跟进状态、查看转化漏斗 |

## 数据

演示数据位于 `src/data/mock.js`。用户输入新行业时，浏览器会动态生成对应的示例任务、视频与评论，无需配置后台。

采集、客户和统计展示用于演示，不会连接或抓取抖音、小红书等平台，也不会跨设备同步数据。

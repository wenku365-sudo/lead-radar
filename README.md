> 纯前端演示项目：所有数据为前端 mock 数据，**不连接真实平台、不做真实爬虫、无后端、无数据库、无需登录**。

## 本地运行

要求 Node.js ≥ 18：

```bash
npm install
npm run dev      # 开发服务器 http://127.0.0.1:5188
npm run build    # 生产构建，产物在 dist/
npm run preview  # 预览构建产物
```

## 部署

推送到 `main` 分支后，`.github/workflows/deploy.yml` 会自动构建并发布到 GitHub Pages，无需手动操作。

首次使用需在仓库 **Settings → Pages → Source** 选择 **GitHub Actions**。

构建时会注入 `GH_PAGES_BASE=/<仓库名>/` 作为资源前缀（`vite.config.js`），若部署到根域名可将该变量改为 `/`。

## 技术栈

React 18 + Vite 5，纯前端 SPA，状态全部保存在前端 React State 中。
